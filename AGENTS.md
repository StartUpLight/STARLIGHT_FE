# Repository Guidelines

## Commit Message

Use the existing repository commit style:

```text
type: (SRLT-issue-number) summary
```

Examples:

```text
feat: (SRLT-148) AI리포트 채점 결과 로딩 시 텍스트 수정 및 버튼 추가
fix: (SRLT-128) 프로모션 기간동안 결제창 안보이도록 수정
chore: (SRLT-127) 프로모션 기간 수정
```

- Use `feat` for new features or visible additions.
- Use `fix` for bug fixes or behavior corrections.
- Use `chore` for configuration, maintenance, or non-feature changes.
- Replace only the issue number with the current JIRA issue when reusing an existing message style.
